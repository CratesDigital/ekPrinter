# ekPrinter

**طباعة صامتة من تطبيقات الويب إلى طابعات Windows.** برنامج صغير يعمل بجوار الساعة على جهاز الكاشير: تُرسل صفحة الويب المستند إليه، فيطبعه مباشرةً على طابعة الإيصالات أو الملصقات أو الطابعة المكتبية — بدون نافذة طباعة، وبدون رسالة ثقة مع كل طباعة، وبعربية تُطبع بشكل صحيح.

[English](README.md) · [واجهة HTTP](docs/api.md) · [ملاحظات التصميم](docs/design.md) · [الأمان](SECURITY.md)

## المشكلة التي يحلها

لا يمكن لنقطة البيع أن تُظهر نافذة الطباعة مع كل إيصال، والمتصفح لا يطبع بصمت من تلقاء نفسه. الحل المعتاد برنامج محلي، والبرنامج المعتاد يثق بالموقع عن طريق شهادة موقّعة: إما أن تشتريها، أو تنسخ شهادة ذاتية التوقيع إلى مجلد البرنامج على كل جهاز بصلاحيات المسؤول، أو تظهر رسالة ثقة مع كل طباعة.

يثق ekPrinter بالموقع بطريقة إقران الأجهزة: يقرأ المستخدم رمزًا من ستة أرقام من صفحة البرنامج ويكتبه في الموقع مرة واحدة. بعدها يستطيع هذا الموقع — وهذا الموقع فقط — أن يطبع. لا توجد شهادة تُشترى أو تُثبَّت أو تُجدَّد.

يعرض المستندات بمحرك **Chromium** (محرك WebView2 المدمج في Windows)، وهو نفس المحرك الذي رسم الصفحة على الشاشة. تبقى الحروف العربية متصلة، ويبقى النص من اليمين إلى اليسار بترتيبه الصحيح، وتُطبع الخطوط والباركود كما تظهر. ومع طابعات الإيصالات يستطيع جعل طول الصفحة مساويًا لطول الإيصال بالضبط، فتقطع الطابعة تحت آخر سطر.

## الإعداد، مرة واحدة لكل جهاز

1. **التثبيت.** حمّل `ekPrinter-Setup.exe` من [الإصدارات](https://github.com/CratesDigital/ekPrinter/releases) وشغّله. لا يحتاج صلاحيات المسؤول؛ يُثبَّت في ملف المستخدم نفسه ويعمل تلقائيًا عند كل تسجيل دخول.
2. **الإقران.** تفتح صفحة البرنامج تلقائيًا بعد التثبيت وعليها رمز من ستة أرقام. أدخله في التطبيق الذي تطبع منه. لرؤية الرمز مرة أخرى افتح <http://127.0.0.1:8421/> أو انقر مرتين على أيقونة البرنامج بجوار الساعة.
3. **اطبع صفحة اختبار** من صفحة البرنامج للتأكد من الطابعة ومن أن العربية تُطبع متصلة.

تثبيت واحد يطبع لكل المواقع المقترنة به.

> **سيحذّرك Windows من أن الناشر غير معروف.** توقيع الكود غير متاح بعد؛ تحقق من الملف المحمَّل بمقارنته ببصمة SHA-256 المنشورة مع الإصدار.

**المتطلبات:** Windows 10 أو 11 بنظام 64-بت، مع Microsoft Edge WebView2 Runtime (موجود في Windows 11 وفي Windows 10 المحدَّث؛ وينبّهك المثبّت إن لم يكن موجودًا). الطباعة المباشرة (raw) تعمل بدونه.

## ربط تطبيقك

خمس نقاط اتصال. **[التفاصيل الكاملة في `docs/api.md`](docs/api.md)** (بالإنجليزية).

<div dir="ltr">

```
GET  /v1/ping          is the agent there, is this site paired
POST /v1/pair          six-digit code in, this origin paired
GET  /v1/printers      installed printers, default, status
POST /v1/print/html    HTML document → printer (page size, fit-to-content)
POST /v1/print/raw     bytes → printer (ESC/POS, cash drawer, ZPL/TSPL)
```

</div>

## أثناء التشغيل

يظهر البرنامج كأيقونة بجوار الساعة. انقر بالزر الأيمن لـ:

| | |
|---|---|
| **Open agent page** | رمز الإقران، المواقع المقترنة، الطابعات، صفحة اختبار، آخر المهام (أو انقر مرتين) |
| **Run when Windows starts** | مفعّل افتراضيًا؛ يمكن إيقافه |
| **Quit** | إيقاف البرنامج |
